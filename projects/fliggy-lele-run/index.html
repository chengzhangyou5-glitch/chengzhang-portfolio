飞猪乐乐跑

六一主题游戏化运营活动

  • 运营设计
  • IP 设计
  • LoRA
担任角色
AIGC 设计师
项目时间
2025.02 — 2025.04
项目定位
飞猪 · C 端活动运营

项目背景

围绕飞猪六一主题与 IP 游戏化玩法，以趣味互动促进活动参与和社交传播。

项目目标

统一活动主视觉与 IP 场景表现，支持游戏流程、奖励反馈与分享传播。

核心工作

  • 负责核心运营视觉，完成飞猪 IP 角色延展、场景与页面物料设计。
  • 结合 SD、LoRA 生成并优化素材，沉淀 AI 辅助视觉生产流程。

实际成果

完成活动核心视觉物料及页面设计落地，形成可复用的 IP 素材与制作流程。
